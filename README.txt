GEMINI KEY
The supplied gemini_api_key.txt contains a deliberately invalid dummy key.
On a hosted page, Circuit Studio automatically reads that file unless an existing
or remembered key is already present. It does not connect automatically.

Open AI Setup, replace the dummy key with your real Gemini API key, choose
Remember API key on this device if desired, save settings, and connect.
A saved key takes priority on subsequent visits. Use Clear to remove it.

Do not put a real key in a public GitHub file. Enter it privately in AI Setup.
For a private/local server, the text file may contain one key on one line.
When opening the HTML directly from disk, browsers block automatic neighboring
file reads. In AI Setup, use Choose key text file to select your local file.
Reload key text file explicitly reloads the hosted file.
